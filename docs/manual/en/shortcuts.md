# Keyboard shortcuts

On macOS, read `Ctrl` as `⌘`. Single-key shortcuts (`/`, `n`) do not apply while you type in a text field.

## Everywhere

| Shortcut | Action |
|---|---|
| `Ctrl+K` or `/` | open the palette: find a dossier, a command, a help page |
| `n` | new dossier (*Research* mode only) |
| `Esc` | close the open menu, palette or panel; a click elsewhere closes it too |
| `Ctrl+Shift+1` | show or hide the project bar (Dossiers · Sources · Notes…) |
| `Tab`, `Shift+Tab` | move between controls; a “Skip to content” link comes first |

## Palette, menus and tabs

| Shortcut | Action |
|---|---|
| `↑` `↓` | choose in the palette or a menu |
| `Enter` | run the chosen item |
| `Home`, `End` | first, last item of a menu |
| `←` `→`, `Home`, `End` | move between the Statement, Lean translation and Proof steps of a dossier |

## Send, run, new line

In every field that sends something (new statement, follow-up request, question on a source, explanation, hints,
research instruction, translation correction, Calcul request, notebook assistant), **`Enter` sends** and
**`Shift+Enter` starts a new line**. A small line under the field reminds you.

| Field | `Enter` | `Shift+Enter` |
|---|---|---|
| sending fields (above) | send | new line |
| Calcul code cell | run the cell | new line (keeping the indentation); `Tab` / `Shift+Tab` indents |
| Lean proof edited by hand, exercise fix | check with Lean | new line |
| article, note body, text cell, profile | new line | new line |

In the article and in notes, `Enter` stays a new line: long texts are written there. On a phone or a tablet without
a keyboard, `Enter` is a new line everywhere and the field's button sends. `Ctrl+Enter` sends too.

## Editors (statement, Lean, dossier thread)

| Shortcut | Action |
|---|---|
| `\le` then `Space` or `Tab` | insert a symbol: `\forall` → `∀`, `\R` → `ℝ`, `\le` → `≤`, `\to` → `→`, `\mid` → `∣` (full list in the “Glossary” screen) |
| `Ctrl+Z`, `Ctrl+Shift+Z` | undo, redo |
| `Tab`, `Shift+Tab` | indent, unindent (in the Lean editor) |

In a natural-language statement, abbreviations are not expanded between `$…$`, to keep the LaTeX.

## Desktop application

| Shortcut | Action |
|---|---|
| `Ctrl+Shift+K` | change server |
