# Keyboard shortcuts

On macOS, read `Ctrl` as `⌘`. In the Lean editor, `\` followed by a name inserts a symbol: `\forall` → `∀`,
`\R` → `ℝ`, `\le` → `≤`, `\to` → `→`, `\mid` → `∣`.
