# Raccourcis clavier

Sur macOS, `Ctrl` se lit `⌘`. Dans l'éditeur Lean, `\` suivi d'un nom insère un symbole : `\forall` → `∀`,
`\R` → `ℝ`, `\le` → `≤`, `\to` → `→`, `\mid` → `∣`.

<!-- verify after integration: S-D completes this table from the web UI (CommandPalette, editor keymap) -->

| Raccourci | Action | Où |
|---|---|---|
| `Ctrl+K` | chercher (dossiers, commandes, aide) | partout |
| `Ctrl+Entrée` | envoyer la demande | fil du dossier |
| `Échap` | fermer la fenêtre ou le menu ouvert | partout |
| `Ctrl+Maj+K` | changer de serveur | application de bureau |
| — | *à compléter* | |
