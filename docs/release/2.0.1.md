## Français

**Installation guidée**
- Nouvel installateur graphique `Madalean-installer.run` : téléchargez-le, rendez-le exécutable (clic droit ›
  Propriétés › « Autoriser l'exécution », ou `chmod +x Madalean-installer.run`), double-cliquez. Il vérifie son
  intégrité, examine votre machine, propose le meilleur plan (réutiliser SageMath ou TeX Live déjà installés, modèle
  local conseillé ou non) et montre l'installation en direct dans votre navigateur.
- Le même assistant dans le terminal : `./install.sh`. Sans question : `./install.sh --yes`.
- Vos choix sont gardés et appliqués au premier démarrage.

téléchargements classés serveur / clients, toujours vers la dernière version.

**Applications** — « À propos » avec les coordonnées de l'auteur dans les applications Android et de bureau.

**Interface** — (à compléter : nouvelle présentation de l'application web, session S-AK).

Fichiers de cette version (noms stables, liens « latest ») : `Madalean-installer.run`, `madalean-server.tar.gz`,
`Madalean-x86_64.AppImage`, `Madalean-android.apk` (+ par processeur), `SHA256SUMS`, `SHA256SUMS.sig`.

## English

**Guided install**
- New graphical installer `Madalean-installer.run`: download it, make it executable (right-click › Properties ›
  “Allow executing”, or `chmod +x Madalean-installer.run`), double-click it. It checks its integrity, examines your
  machine, proposes the best plan (reuse SageMath or TeX Live already installed, local model recommended or not) and
  shows the installation live in your browser.
- The same assistant in the terminal: `./install.sh`. Without questions: `./install.sh --yes`.
- Your choices are kept and applied at first start.

**Site** — new home page, complete installation and first-configuration guide, About page; downloads grouped server /
clients, always to the latest version.

**Apps** — About with the author's contacts in the Android and desktop apps.

**Interface** — (to complete: new presentation of the web app, session S-AK).

Release files (stable names, “latest” links): `Madalean-installer.run`, `madalean-server.tar.gz`,
`Madalean-x86_64.AppImage`, `Madalean-android.apk` (+ per processor), `SHA256SUMS`, `SHA256SUMS.sig`.

Release steps: `scripts/build_appimage.sh`, `scripts/build_apk.sh`, `scripts/stage_release.sh dist/release`,
`scripts/sign_release.sh dist/release` (writes site/updates/stable.json + .sig), upload every file of dist/release.
