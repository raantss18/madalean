Installons Madalean sur cet ordinateur

Cet ordinateur deviendra l'hôte : il fera tout le calcul. Vos autres appareils s'y relieront ensuite.

  • Tout s'installe dans un seul dossier de votre compte, sans mot de passe administrateur.
  • L'assistant regarde ce qui est déjà installé et vous conseille ; vous gardez le dernier mot.
  • Chaque fichier téléchargé est vérifié (empreinte SHA-256).

  1. Une clé de modèle en ligne — gratuite (par exemple Google Gemini ou Mistral) : Réglages › Modèles et clés.

  2. Le mode de travail — en ligne, automatique ou local ; Apprendre ou Recherche.
    3. 
        
  3. Ce qui part tout seul — exécution du code proposé par les modèles (après votre accord par défaut), mises à jour, chef d'orchestre.
    4. 
        
  4. Vos appareils — téléphone, tablette, autre ordinateur : Réglages › Appareils.
